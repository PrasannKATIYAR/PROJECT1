for i=1:6:CMPLXCOLS

    V1XCoor(:,count) = ComplexVolts(:,i);
    V1YCoor(:,count) = ComplexVolts(:,i+1);

V2COMPLEXBUS = V2XCoor+j*V2YCoor;
V3COMPLEXBUS = V3XCoor+j*V3YCoor;

V2COMPLEXLoads = zeros(1440,55);
V3COMPLEXLoads = zeros(1440,55);

        V2COMPLEXLoads(:,i) = V2COMPLEXBUS(:,k);
        V3COMPLEXLoads(:,i) = V3COMPLEXBUS(:,k);
        i=i+1;
    end

a_Fortescue = -0.5 + j*(sqrt(3)/2);

Numerator = abs(V1COMPLEXLoads + ((a_Fortescue^2).*V2COMPLEXLoads) + (a_Fortescue.*V3COMPLEXLoads));
Denominator = abs(V1COMPLEXLoads + (a_Fortescue.*V2COMPLEXLoads) +((a_Fortescue^2).*V3COMPLEXLoads));
Unbalance = (Numerator./Denominator)*100; 




CODE EXPLANATION:

This MATLAB code calculates voltage unbalance at each node of a power distribution system based on complex bus voltages and load voltages.

1. Preallocation of Coordinate Matrices:
Six matrices (V1XCoor, V1YCoor, V2XCoor, V2YCoor, V3XCoor, V3YCoor) are preallocated to hold the real and imaginary parts of complex voltage data for three phases (V1, V2, V3) at each of the 907 nodes over 1440 time intervals. Preallocating matrices improves computational efficiency.

2. Sorting Complex Bus Voltages:
The size of the ComplexVolts matrix is determined. A loop iterates through the columns of ComplexVolts in steps of 6, assigning the real and imaginary components of each phase's voltages to the corresponding coordinates matrices (V1XCoor, V1YCoor, etc.). Each phase's voltage is paired with its respective x and y coordinates, indexed by count.

3. Creating Complex Voltage Matrices:
Complex voltage matrices for each phase (V1COMPLEXBUS, V2COMPLEXBUS, V3COMPLEXBUS) are created using the preallocated coordinate matrices. The imaginary unit j is used to combine the real (x-coordinates) and imaginary (y-coordinates) parts into complex numbers.

4. Preallocation for Load Voltages:
Three additional matrices (V1COMPLEXLoads, V2COMPLEXLoads, V3COMPLEXLoads) are preallocated to store the complex voltages at the loads connected to specific buses.

5. Filling Load Voltage Matrices:
Another loop iterates over the bus numbers stored in Loads_Connected_to_Bus_No. For each bus number (k), the corresponding complex voltage data for each phase is extracted from the complex bus matrices and stored in the load voltage matrices.

6. Fortescue's Operator:
Fortescue's operator a_Fortescue is defined as a complex number, which helps in calculating the symmetrical components of the voltages. This operator is crucial for determining the unbalance in the three-phase system.

7. Calculating Unbalance:
The numerator for the unbalance calculation is computed by summing the complex voltages of all three phases, each multiplied by the appropriate powers of Fortescue's operator.
The denominator is similarly calculated but with the phases rearranged.
Voltage unbalance is then computed as the ratio of the numerator to the denominator, multiplied by 100, following the definition according to IEC 61000-3-14 standards.

Purpose of Plot Export Types:
Interactive .fig files are useful when further editing or interaction with the plot is required in MATLAB. This is beneficial for data exploration and detailed analysis.
Non-interactive PNG files are static images meant for use in external documents, presentations, or when sharing the results without needing the user to modify the plots.

Stacked bar charts showing power losses.
